# @context-mcp/linux-x64

context-mcp binary for Linux x64 systems.

This package contains the native binary for context-mcp compiled for Linux x64 architecture.

## Installation

This package is automatically installed as an optional dependency when you install `@context-mcp/server` on a Linux x64 system.

```bash
npm install @context-mcp/server
```

## Usage

You should not need to install this package directly. Use the main `@context-mcp/server` package instead.
