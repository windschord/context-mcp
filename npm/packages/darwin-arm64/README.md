# @context-mcp/darwin-arm64

context-mcp binary for macOS ARM64 systems.

This package contains the native binary for context-mcp compiled for macOS ARM64 architecture (Apple Silicon Macs).

## Installation

This package is automatically installed as an optional dependency when you install `@context-mcp/server` on a macOS ARM64 system.

```bash
npm install @context-mcp/server
```

## Usage

You should not need to install this package directly. Use the main `@context-mcp/server` package instead.
