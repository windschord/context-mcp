# @context-mcp/win32-x64

context-mcp binary for Windows x64 systems.

This package contains the native binary for context-mcp compiled for Windows x64 architecture.

## Installation

This package is automatically installed as an optional dependency when you install `@context-mcp/server` on a Windows x64 system.

```bash
npm install @context-mcp/server
```

## Usage

You should not need to install this package directly. Use the main `@context-mcp/server` package instead.
